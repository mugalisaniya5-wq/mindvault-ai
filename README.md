#  MindVault AI

A personal memory and task management application built using Python and Streamlit.

## Features
- Dashboard to view memories and tasks
-  Save and organize personal memories
-  Search saved memories using the AI Assistant
-  Create tasks and track completion
-  Voice notes with speech-to-text conversion

##  Technologies Used
- Python
- Streamlit
- SQLite
- streamlit-mic-recorder

##  How to Run
Install the required libraries:

pip install streamlit streamlit-mic-recorder

Run the application:

streamlit run app.py
